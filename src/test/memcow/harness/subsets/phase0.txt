# phase0 --- the core-regression subset for plan §7.1.
#
# §7.1 names categories, not tests: "DDL, DML, vacuum, sequences, temp tables,
# COPY, index builds".  This file is that mapping.  Selection rule: a test earns
# a place here if it drives the smgr surface memcow has to reimplement --
# smgrcreate / smgrextend / smgrstartreadv / smgrreadv / smgrwritev /
# smgrtruncate / smgrunlink -- and if its expected output is deterministic.
# Pure expression/type/planner tests are excluded: they exercise no storage the
# type tests do not already reach through test_setup's tables, and every extra
# test is extra runtime on every matrix cell.
#
# The tests are run through a filtered copy of src/test/regress/parallel_schedule
# (see gen_schedule.py), so group membership and ordering stay exactly as
# upstream intends them.  Never reorder by hand.
#
# One test per line; # starts a comment.
